## Como correr localmente

O projeto usa módulos JavaScript e `fetch`, que não funcionam ao abrir o `index.html` com duplo clique. É preciso um servidor local:

1. Abrir a pasta no VS Code.
2. Instalar a extensão **Live Server**.
3. Botão direito no `index.html` → **Open with Live Server**.
